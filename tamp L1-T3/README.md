# 🌡️ Task 3 — TempX Temperature Converter

## 📌 Project Overview

TempX is an interactive temperature conversion web application built using HTML, CSS, and vanilla JavaScript.

The application allows users to enter a temperature and select Celsius, Fahrenheit, or Kelvin as the input unit. It then calculates and displays the corresponding values for all three units.

### Main Features

- Celsius input
- Fahrenheit input
- Kelvin input
- Celsius → Fahrenheit conversion
- Celsius → Kelvin conversion
- Fahrenheit → Celsius conversion
- Fahrenheit → Kelvin conversion
- Kelvin → Celsius conversion
- Kelvin → Fahrenheit conversion
- Decimal value support
- Input validation
- Real-time validation
- Error messages
- Absolute zero validation
- Responsive UI
- Enter-key support
- Results displayed in separate cards

### Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
